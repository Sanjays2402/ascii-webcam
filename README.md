# ASCII Webcam 📹

Your webcam feed converted to ASCII art in real-time.

![Screenshot](screenshot.png)

## Features

- **Real-time ASCII rendering** — Webcam feed converted to text characters at full speed
- **Color mode** — Preserves original colors in the ASCII output
- **Monochrome mode** — Classic black-and-white ASCII art
- **Multiple character ramps** — Simple, Detailed, Blocks, Minimal
- **Adjustable resolution** — Control character density from sparse to dense
- **Invert mode** — Flip brightness mapping
- **Dark/Light theme** — Toggle between dark and light backgrounds
- **FPS counter** — Monitor rendering performance
- **Mirrored output** — Selfie-style mirroring for natural viewing

## Usage

1. Open `index.html` in any modern browser
2. Click **Start Camera** and allow camera access
3. Adjust settings in the top toolbar

No build step required. Works best in Chrome/Firefox.

## Privacy

All processing happens locally in your browser. No video data is sent anywhere.
